# Customer_behaviour_analysis-
# Customer Shopping Behavior Analysis
# 1. Project Overview
This project analyzes customer shopping behavior using transactional data from 3,900
purchases across various product categories. The goal is to uncover insights into spending
patterns, customer segments, product preferences, and subscription behavior to guide strategic
business decisions.
# Objectives
* Collect and understand customer shopping data to identify purchasing patterns and customer behavior.
* Clean and preprocess the dataset using Python, including handling missing values, standardizing columns, and creating useful features.
* Analyze customer behavior using SQL to identify revenue trends, customer segments, product performance, discounts, subscriptions, and purchase patterns.
* Identify high-performing products and customer segments based on sales, ratings, purchase frequency, and revenue contribution.
* Analyze the impact of discounts, subscriptions, and shipping preferences on customer purchasing behavior.
* Develop an interactive Power BI dashboard to visualize key KPIs, trends, and business insights.
* Generate actionable business recommendations to improve customer engagement, loyalty, marketing strategies, product positioning, and subscription adoption.

# 2. Dataset Summary

- Rows: 3,900
- Columns: 18
- Key Features:
- Customer demographics (Age, Gender, Location, Subscription Status)
- Purchase details (Item Purchased, Category, Purchase Amount, Season, Size, Color)
- Shopping behavior (Discount Applied, Promo Code Used, Previous Purchases, Frequency of
Purchases, Review Rating, Shipping Type)
- Missing Data: 37 values in Review Rating column
